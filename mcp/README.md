# OPDIS contributor MCP

[Open the server source on GitHub](https://github.com/Haselton/Opdis-/tree/feature/contributor-mcp/mcp) · [Read the project briefing](../PROJECT_PROGRESS.md#contributor-briefing) · [Connect or run locally](../CONTRIBUTING.md#connect-the-contributor-mcp)

Open the repository in VS Code or Claude Code and enable the configured **opdis** server. For another Streamable HTTP client, add:

    https://opdis-contribute.haseltonmediagroup.chatgpt.site/mcp

> Give me the OPDIS project briefing and one small change I can make with my coding assistant and no GPU. How will I know it works?

The briefing includes the goal, evidence, next milestones and an open task with a first step and acceptance check. The other tools find tasks, show the sources behind research claims and validate draft test cases. The implementation is available on the public contributor branch while [pull request #2](https://github.com/Haselton/Opdis-/pull/2) awaits independent review.
